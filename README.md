# System Performance Monitoring Dashboard

## Project Overview

The **System Performance Monitoring Dashboard** is a data analytics project designed to monitor, analyze, and visualize critical system performance metrics such as CPU usage, memory utilization, disk I/O, and latency.

The goal is to enable **real-time performance tracking**, detect bottlenecks, and support **data-driven decision-making** to improve system efficiency and reliability.

---

## Business Problem

Modern IT systems often face performance issues such as:

* High CPU utilization during peak hours
* Memory saturation leading to slow performance
* Increased latency affecting user experience
* Lack of real-time monitoring and alerting

Traditional monitoring methods are **manual, reactive, and inefficient**, leading to:

* System downtime
* Reduced productivity
* Poor user experience

---

## Solution

Developed an **interactive Power BI dashboard** that:

* Monitors key system metrics in real-time
* Identifies performance bottlenecks
* Detects anomalies and unusual patterns
* Enables proactive system management

---

## Dataset

* Duration: 30 days
* Frequency: Hourly data
* Metrics included:

  * CPU Usage (User, System, I/O Wait)
  * Memory Usage (Used, Available)
  * Disk I/O Operations
  * System Load
  * Latency

---

## Tools & Technologies

* **Excel** – Initial data exploration & validation
* **SQL** – Data querying & aggregation
* **Python (Pandas, Matplotlib)** – Data cleaning & analysis
* **Power BI** – Dashboard creation & visualization

---

## Key Insights

* Peak CPU usage observed during specific time intervals (high workload periods)
* Strong correlation between **CPU usage and latency**
* Memory usage mostly stable with occasional spikes
* Disk activity increases during peak system load
* Identified anomalies indicating potential system issues

---

## Business Recommendations

* Schedule heavy workloads during off-peak hours
* Implement real-time monitoring & alert systems
* Optimize resource allocation
* Use predictive analysis for capacity planning
* Improve application efficiency to reduce resource consumption

---

## Dashboard Features

* Interactive filters (time-based analysis)
* Drill-down capability for deeper insights
* Real-time performance tracking
* KPI cards for quick overview

---

## Project Outcome

* Improved visibility into system performance
* Reduced risk of system failures
* Enabled proactive decision-making
* Enhanced overall system efficiency
